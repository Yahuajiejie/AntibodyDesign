# AI 抗体从头设计初学者实验方案

## 0. 方案定位

这份方案面向刚开始进入 AI 抗体设计项目的学习者，目标不是一步到位训练出最强模型，而是先搭建一条可理解、可复现、可展示的实验流程。

最终希望你能理解并跑通以下闭环：

```text
抗原输入
  -> 表位分析
  -> 抗体候选生成
  -> 序列合法性检查
  -> 结构预测
  -> 结合界面评估
  -> 表达/聚集/稳定性筛选
  -> 候选排序
  -> 输出推荐抗体
```

对于 Bio-OS 抗体设计赛题，这条流程的核心目标是：

- 生成可被抗体注释系统识别的 VH/VL 或 VHH 序列；
- 尽量命中目标抗原表位；
- 尽量提高预测结合能力；
- 降低表达失败和聚集风险；
- 最终筛选出 6 条风格不同、风险分散的候选抗体。

## 1. 项目总目标

本实验以 Nipah virus G protein 为目标抗原，学习如何从抗原信息出发，构建一套 AI 辅助抗体设计流程。

本方案建议先完成一个“小而完整”的原型系统，而不是直接追求复杂微调。

推荐阶段目标：

| 阶段 | 目标 |
| --- | --- |
| 第 1 阶段 | 理解抗体序列、抗原序列、CSV 数据和结构文件 |
| 第 2 阶段 | 学会分析抗原表面和候选表位 |
| 第 3 阶段 | 使用已有模型或模板生成抗体候选 |
| 第 4 阶段 | 检查抗体序列是否合法、新颖、可注释 |
| 第 5 阶段 | 预测抗体-抗原复合物结构 |
| 第 6 阶段 | 建立基础打分和排序规则 |
| 第 7 阶段 | 尝试用 FLAb 数据训练简单性质预测模型 |

## 3. 实验阶段一：准备抗原和参考抗体

### 3.1 输入数据

目标抗原：

```text
Nipah virus G protein
```

比赛示例中给出的商业化抗原是带 His tag 的 Nipah G protein。建议保存为 FASTA：

```text
data/antigen/nipah_g_his.fasta
```

同时保存去除 His tag 的版本：

```text
data/antigen/nipah_g_nohis.fasta
```

原因：His tag 用于实验检测和纯化，但通常不是我们希望抗体结合的主体区域。

### 3.2 参考抗体

保存阳性对照抗体：

- m102.4，Fv；
- n425，VHH；
- HENV-26，Fv。

建议保存为：

```text
data/references/positive_controls.fasta
```

### 3.3 学习目标

这一阶段要搞清楚：

- 什么是抗原；
- 什么是 VH、VL、VHH；
- 什么是 Fv 和 scFv；
- 为什么比赛要求只提交抗体可变区；
- 为什么 His tag 不应该作为主要设计表位。

### 3.4 成功标志

完成以下文件：

```text
data/antigen/nipah_g_his.fasta
data/antigen/nipah_g_nohis.fasta
data/references/positive_controls.fasta
```

并能说明每条序列是什么。

## 4. 实验阶段二：抗原结构准备

### 4.1 推荐方法

优先级如下：

1. 如果 PDB 中有 Nipah G protein 相关结构，优先使用实验结构；
2. 如果没有合适结构，使用 AlphaFold、Boltz、Chai-1 或其他结构预测工具；
3. 如果只是学习演示，可以先使用公开结构或预测结构作为临时输入。

### 4.2 需要关注的问题

抗原结构准备时，要检查：

- 是否包含目标检测区域；
- 是否包含 His tag；
- 是否有缺失残基；
- 是否有明显低置信度区域；
- 是否有糖基化位点；
- 是否是单体、二聚体或四聚体；
- 表面区域是否可被抗体接触。

### 4.3 输出文件

建议输出：

```text
results/epitope_analysis/nipah_g_structure.pdb
results/epitope_analysis/structure_notes.md
```

`structure_notes.md` 中记录：

- 结构来源；
- 是否预测结构；
- 是否删除 His tag；
- 哪些区域不可靠；
- 后续表位分析使用哪个链。

### 4.4 成功标志

你能打开 PDB 文件，看到 Nipah G protein 的三维结构，并能说明哪些区域适合作为表位候选。

## 5. 实验阶段三：表位分析

### 5.1 表位选择原则

好的候选表位通常满足：

- 位于抗原表面；
- 结构稳定；
- 不是 His tag；
- 不是明显低置信度柔性尾部；
- 在相关病毒株中较保守；
- 靠近功能关键区域；
- 不被糖基化严重遮挡。

### 5.2 初学者可做的分析

不需要一开始就做很复杂的表位预测。可以先做四件事：

1. 标出抗原表面残基；
2. 标出保守区域；
3. 标出潜在糖基化位点；
4. 参考阳性对照抗体可能结合区域。

### 5.3 输出

建议输出一个表位候选表：

```text
results/epitope_analysis/candidate_epitopes.csv
```

字段示例：

```text
epitope_id,residue_range,reason,risk,priority
E1,120-145,表面暴露且较保守,附近可能有糖基化,high
E2,260-285,靠近功能区域,柔性较高,medium
```

### 5.4 成功标志

至少提出 2 到 4 个候选表位，并能解释为什么选择它们。

## 6. 实验阶段四：候选抗体生成

### 6.1 初学者推荐路线

建议先从 VHH 开始学习，再扩展到 VH/VL。

原因：

- VHH 只有一条链；
- 序列格式简单；
- 结构预测和编号更容易；
- 湿实验表达通常更友好；
- 更适合快速形成可展示结果。

### 6.2 候选来源

候选抗体可以来自三类方法：

| 方法 | 难度 | 说明 |
| --- | --- | --- |
| 模板改造 | 低 | 使用已有 VHH/VH 框架，改造 CDR |
| 语言模型生成 | 中 | 使用 IgLM、AntiBERTy、ESM 类模型生成或重采样序列 |
| 结构生成 | 高 | 使用 RFdiffusion 或类似模型生成表位条件结合结构 |

初学者建议顺序：

```text
模板改造
  -> 语言模型生成
  -> 结构生成
```

### 6.3 候选规模

不要一开始只生成 6 条。建议先生成较大的候选池：

```text
VHH 候选：500 - 5000 条
Fv/scFv 候选：100 - 1000 对
```

然后逐层过滤。

### 6.4 输出

```text
results/generated_sequences/vhh_candidates_raw.csv
results/generated_sequences/fv_candidates_raw.csv
```

字段示例：

```text
candidate_id,type,heavy,light,source,target_epitope
VHH_0001,VHH,EVQLVES...,NA,template_mutation,E1
FV_0001,Fv,EVQLVES...,DIQMTQS...,plm_generation,E2
```

### 6.5 成功标志

你至少能生成一批候选抗体序列，并知道每条序列来自哪个方法、针对哪个表位。

## 7. 实验阶段五：抗体编号与合法性检查

### 7.1 为什么要做

比赛要求提交序列必须属于抗体可变区，并能被常用抗体编号/注释系统识别。

如果生成序列无法被编号，即使模型分数很高，也不适合作为候选。

### 7.2 推荐工具

可以使用：

- ANARCI；
- IgBLAST；
- AbNumber；
- abYsis；
- IMGT numbering。

### 7.3 检查内容

需要检查：

- 是否能识别为 VH、VL 或 VHH；
- framework 是否完整；
- CDR1、CDR2、CDR3 是否存在；
- CDR3 长度是否极端；
- 是否有非法氨基酸；
- 是否有异常半胱氨酸；
- 是否存在 stop codon 或非标准字符。

### 7.4 输出

```text
results/numbering/candidates_numbered.csv
```

字段示例：

```text
candidate_id,type,numbering_pass,v_gene_like,cdr1,cdr2,cdr3,warning
VHH_0001,VHH,true,IGHV3,GFXXXX,YXXXXX,ARXXXXXX,none
```

### 7.5 成功标志

保留所有能够被正常编号的候选，删除明显不合法序列。

## 8. 实验阶段六：新颖性检查

### 8.1 为什么要做

比赛明确要求提交序列不能与已知目标抗原抗体过于相似。

基本规则：

- Fv 抗体 VH 或 VL 全长 identity 不高于 90%；
- Fv 抗体 VH CDR3 或 VL CDR3 identity 不高于 70%；
- VHH 全长 identity 不高于 90%；
- VHH CDR3 identity 不高于 70%；
- 不能明显复刻、轻微改写或拼接已知抗体。

### 8.2 推荐做法

至少与以下抗体比较：

- m102.4；
- n425；
- HENV-26。

如果有能力，可以再与 SAbDab、OAS、INDI2、ANDD 中的抗体序列比较。

### 8.3 输出

```text
results/numbering/novelty_check.csv
```

字段示例：

```text
candidate_id,max_full_identity,max_cdr3_identity,nearest_known_antibody,pass
VHH_0001,0.72,0.45,n425,true
```

### 8.4 成功标志

候选池中所有保留序列都满足比赛相似性要求。

## 9. 实验阶段七：结构预测

### 9.1 预测内容

对候选抗体进行两类结构预测：

1. 抗体单体结构预测；
2. 抗体-抗原复合物结构预测。

单体结构用于看抗体本身是否合理；复合物结构用于看是否可能结合目标表位。

### 9.2 推荐工具

可以选择：

- IgFold；
- AlphaFold-Multimer；
- AlphaFold 3；
- Boltz；
- Chai-1；
- RosettaDock；
- HDOCK。

初学者建议先用较容易运行的工具进行学习，再逐渐换成更强模型。

### 9.3 需要记录的指标

结构预测后，记录：

- 抗体结构是否完整；
- CDR loop 是否异常；
- 抗体是否靠近目标表位；
- 界面接触数量；
- 预测置信度；
- PAE 或类似不确定性指标；
- 是否存在明显原子冲突；
- 抗体是否错误结合到 His tag 或无关区域。

### 9.4 输出

```text
results/structure_prediction/complex_predictions/
results/structure_prediction/structure_scores.csv
```

字段示例：

```text
candidate_id,target_epitope,predicted_epitope_hit,interface_contacts,confidence,clash_risk,pass
VHH_0001,E1,true,28,0.82,low,true
```

### 9.5 成功标志

得到一批结构上看起来合理、且预测能接触目标表位的候选。

## 10. 实验阶段八：可开发性筛选

### 10.1 为什么重要

比赛湿实验评分不仅看结合，还看：

- 表达水平；
- 聚集倾向。

所以候选抗体不能只追求预测亲和力。一个结合分高但极易聚集的序列，很可能在湿实验中失败。

### 10.2 基础理化指标

先计算简单指标：

- 分子量；
- pI；
- 净电荷；
- GRAVY；
- 芳香族比例；
- instability index；
- CDR3 长度；
- CDR3 疏水残基比例；
- N-糖基化位点；
- 游离半胱氨酸；
- 连续疏水片段。

### 10.3 使用 FLAb

FLAb 可以帮助训练或校准以下预测器：

| 性质 | FLAb 目录 |
| --- | --- |
| 结合能力 | `data/binding/` |
| 表达水平 | `data/expression/` |
| 聚集倾向 | `data/aggregation/` |
| 热稳定性 | `data/thermostability/` |
| 多反应性 | `data/polyreactivity/` |

初学者不建议一开始训练大模型。可以先做简单模型：

```text
序列特征 + ridge regression
序列特征 + random forest
ESM embedding + XGBoost
AntiBERTy embedding + MLP
```

### 10.4 输出

```text
results/developability/developability_scores.csv
```

字段示例：

```text
candidate_id,expression_score,aggregation_risk,tm_score,polyreactivity_risk,developability_pass
VHH_0001,0.77,0.18,0.69,0.22,true
```

### 10.5 成功标志

你能解释为什么某些候选被淘汰：例如 CDR3 过疏水、聚集风险高、pI 极端、预测表达差。

## 11. 实验阶段九：综合排序

### 11.1 排序原则

最终不要只选分数最高的 6 条，而是选：

- 高结合潜力；
- 低表达风险；
- 低聚集风险；
- 合法可编号；
- 与已知抗体不过度相似；
- 表位有一定多样性；
- 序列和结构有一定多样性。

### 11.2 初始打分公式

可以先用简单加权：

```text
Total Score =
  0.45 * Binding_or_Interface_Score
+ 0.20 * Expression_Score
+ 0.15 * Aggregation_Safety_Score
+ 0.10 * Stability_Score
+ 0.10 * Novelty_and_Diversity_Score
```

注意：比赛湿实验中 SPR 亲和力权重是 70%，但计算预测亲和力误差较大，所以学习阶段可以适当提高表达和聚集的权重，降低全军覆没风险。

### 11.3 输出

```text
results/final_selection/final_candidates.csv
results/final_selection/final_report.md
```

`final_candidates.csv` 字段示例：

```text
rank,candidate_id,type,heavy,light,target_epitope,total_score,reason
1,VHH_0123,VHH,EVQLVES...,NA,E1,0.86,界面好且聚集风险低
```

### 11.4 成功标志

你能选出 6 条候选，并为每条写出推荐理由。

## 12. 实验阶段十：尝试微调模型

这一阶段适合在跑通基础流程之后再做。

### 12.1 不建议首先微调 RFdiffusion

RFdiffusion 类模型很强，但微调难度高，需要：

- 抗体-抗原复合物结构数据；
- 表位接触标注；
- 抗体编号和 CDR 区域标注；
- 多卡训练经验；
- 对扩散模型训练细节的理解。

因此初学者不建议把它作为第一步。

### 12.2 更推荐先微调 inverse folding 或性质预测器

推荐优先级：

```text
FLAb 性质预测器
  -> 抗体 inverse folding 模型
  -> 抗体语言模型 LoRA/adapter
  -> 表位条件结构生成模型
```

### 12.3 inverse folding 监督函数

目标：给定抗体结构或复合物结构，预测氨基酸序列。

基础损失：

```text
L_seq = - Σ log P(x_i | backbone)
```

抗体任务中建议对 CDR 和界面残基加权：

```text
L_inverse = Σ w_i * CE(x_i, p_i)
```

推荐权重：

```text
framework: 1
CDR1/CDR2: 2
CDR3: 3 或 4
interface residues: 3
```

### 12.4 性质预测监督函数

可以用 FLAb 做多任务学习：

```text
L_property =
  λ_bind * L_bind
+ λ_expr * L_expr
+ λ_agg  * L_agg
+ λ_tm   * L_tm
+ λ_poly * L_poly
```

其中：

- binding affinity：MSE、Huber loss 或 ranking loss；
- expression：MSE 或 Huber loss；
- aggregation：MSE 或 ranking loss；
- thermostability：MSE；
- bind/no bind：binary cross entropy；
- polyreactivity：MSE 或 ranking loss。

对于比赛，更推荐加入排序损失：

```text
L_rank = max(0, margin - S_good + S_bad)
```

或者：

```text
L_pref = -log sigmoid(S_good - S_bad)
```

### 12.5 成功标志

微调模型不是看训练 loss 降低就够了，还要看：

- 在保留测试集上是否有相关性提升；
- 是否能区分高表达和低表达抗体；
- 是否能区分高聚集风险和低聚集风险抗体；
- 生成候选是否仍能被抗体编号系统识别；
- 是否没有明显牺牲多样性。

## 13. 推荐学习顺序

建议按下面顺序学习：

1. 抗体基础：VH、VL、VHH、CDR、framework；
2. 抗体编号：IMGT、Chothia、ANARCI；
3. 抗原结构：PDB、FASTA、表面残基、糖基化位点；
4. 结构预测：IgFold、AlphaFold-Multimer、Boltz、Chai；
5. 序列生成：语言模型、模板突变、CDR 采样；
6. 逆折叠：ProteinMPNN、AbMPNN、IgDesign；
7. 可开发性：表达、聚集、热稳定性、多反应性；
8. FLAb 数据建模；
9. 多目标排序；
10. 再考虑微调生成模型。

## 14. 最小可展示版本

如果时间紧，最小可展示版本可以只做：

```text
1. 输入 Nipah G protein 序列
2. 准备或预测抗原结构
3. 选择 2-3 个候选表位
4. 生成 100-500 条 VHH 候选
5. 使用 ANARCI / AbNumber 做编号检查
6. 做相似性过滤
7. 预测候选与抗原复合物
8. 计算界面和可开发性指标
9. 排序并输出 6 条候选
10. 写出每条候选的推荐理由
```

这个版本已经足够作为学习资料和初步项目展示。

## 16. 一句话总结

这个项目的学习主线不是“先训练一个很大的模型”，而是先理解并搭建抗体设计闭环：生成候选、验证合法性、预测结构、评估结合、过滤可开发性、综合排序。等这条闭环跑通后，再把你们的显卡资源投入到 inverse folding 微调、FLAb 性质预测器和最终排序模型上，收益会更稳定。
