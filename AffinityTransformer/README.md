# 抗体-抗原亲和力排序模型项目介绍

## 1. 项目背景

抗体药物发现的早期阶段通常需要在大量候选抗体序列中筛选出更有潜力的分子。湿实验能够直接测定抗体与抗原之间的结合能力，但实验成本高、周期长，难以覆盖大规模候选空间。因此，在进入实验验证之前，利用计算模型对候选抗体进行预筛选，是抗体设计流程中具有实际价值的一环。

本项目面向第四届 Bio-OS AI 开源大赛初赛任务，目标是根据给定的抗原信息和一组候选抗体序列，预测这些抗体在同一抗原背景下的相对亲和力强弱，并输出排序结果。模型的最终表现由 Spearman 等级相关系数评价，即关注预测排序与真实实验排序之间的一致程度。

与直接预测某个抗体的绝对 Kd、IC50 或 EC50 数值相比，本项目更关注“哪些候选分子更值得进入后续验证”。这种设定更接近抗体发现早期的实际需求：在候选序列数量很大、实验数据来源复杂且存在批次差异时，可靠的相对排序往往比单个数值的精确回归更有工程意义。

## 2. 问题定义：从亲和力回归到排序学习

抗体-抗原亲和力预测常被直观地理解为回归问题，即输入抗体和抗原序列，输出一个连续的结合强度数值。然而，本任务中的数据来源较为异构，不同数据集可能采用不同的实验体系和测量指标，例如平衡解离常数 Kd、半抑制浓度 IC50、半效应浓度 EC50，以及部分数据集中出现的 fitness 或 log-ratio 类指标。

这些指标并不总是具有相同的物理意义和量纲。即使它们都与结合能力或中和活性有关，也不能简单地在全局范围内进行横向比较。例如，Kd 越小通常代表结合越紧密，而某些 fitness 指标则可能是数值越大越好；不同实验平台之间还可能存在系统性偏移。如果将这些数据强行混合为一个统一的回归目标，模型很容易学习到数据集来源、测量条件或标签尺度差异，而不是真正与抗体-抗原相互作用相关的信号。

因此，本项目将建模目标从“预测绝对数值”调整为“学习相对顺序”。具体而言，模型不要求输出具有明确物理单位的亲和力常数，而是为每个抗体-抗原组合生成一个相对得分。这个得分只在同一抗原、同一指标体系或同一可比实验背景下具有比较意义。通过这种方式，模型能够更自然地对齐 Spearman 排序评价指标，也能降低跨数据集尺度差异对训练过程的干扰。

## 3. 数据特点与主要挑战

本项目使用的数据包含多个来源的抗体-抗原记录，既有结构数据库相关信息，也有序列库和纳米抗体数据。整体来看，数据预处理阶段需要解决四类核心问题。

第一，实验指标异构。不同记录可能使用 Kd、IC50、EC50、fitness 等不同标签。它们的方向、单位和实验含义并不完全一致，不能直接作为同一回归目标使用。

第二，样本之间的可比性有限。只有在相同或相近的抗原背景、实验方法和指标体系下，抗体之间的相对排序才具有明确意义。跨抗原、跨实验平台或跨指标的直接比较，可能引入无关噪声。

第三，抗原信息不完整。部分记录只提供抗体序列，缺少精确的抗原氨基酸序列或结构背景。而抗原信息对于亲和力预测非常关键，因为同一抗体面对不同抗原或突变株时，其结合表现可能发生显著变化。

第四，抗体形态存在差异。传统 Fv 抗体通常包含 VH 与 VL 两条可变区链，而纳米抗体 VHH 只包含单条重链可变区。模型需要在统一框架下处理不同抗体类型，同时避免因简单填充或拼接方式带来的无效计算和错误表征。

围绕这些问题，项目的数据处理流程主要包括：同质分组、标签方向统一、抗原特征补全、抗体序列标准化，以及面向排序训练的样本对构造。

## 4. 同质分组：保证排序关系可比较

排序学习的前提是样本之间具有可比性。对于本项目而言，并不是任意两个抗体都可以直接组成训练样本对。只有当它们对应相同或高度一致的抗原背景，并且使用相同类型的实验指标进行测量时，二者的亲和力高低才具有可靠的比较意义。

因此，我们在数据处理阶段引入同质分组策略。每条记录会根据抗原名称或抗原标识、指标类型、实验方法等信息生成分组标签。模型训练时只在同一分组内部构造成对比较关系，不跨组生成 pair。这样可以尽量避免将不同实验体系下的数值差异误认为真实的亲和力差异。

这一策略的核心思想是：模型不需要在全局范围内判断“某个 Kd 数值是否一定优于某个 IC50 数值”，而是需要在局部可比环境中学习“同一抗原背景下哪个抗体更优”。这既符合 Spearman 排序指标的评价方式，也更贴近抗体筛选中的实际决策场景。

## 5. 标签方向统一：让“分数越大越好”

在完成分组后，不同指标仍需要统一方向。对于 Kd、IC50、EC50 等指标，通常数值越小表示结合越强或功能效应越明显；而对于 fitness、neg_log_kd 等指标，可能本身就是数值越大越好。如果不处理方向差异，模型会在训练时接收到相互矛盾的监督信号。

因此，项目将所有可用于排序的标签转换为统一的正向排序目标：数值越大，表示相对亲和力或活性越强。对于“小值更优”的指标，可以通过取负值、取负对数或按照已有字段含义进行方向反转；对于本身已经是正向含义的指标，则保持原方向。对于含有比值或相对变化含义的标签，需要结合其具体实验定义判断极性。

经过方向统一后，模型输出的相对得分能够与真实标签保持一致的排序语义，从而支持 Pairwise Ranking Loss 的训练。

## 6. 抗原表征：Exact 与 MSA 的双路径设计

抗原信息是抗体亲和力预测中的关键上下文。一个抗体的结合能力并不是由抗体序列单独决定的，而是取决于它与特定抗原表位之间的相互匹配关系。考虑到数据中存在抗原序列缺失或抗原描述不完整的问题，本项目设计了双路径抗原表征方案。

第一条路径是精确序列路径（Exact Path）。该路径尝试根据 UniProt ID、抗原名称、突变株信息或其他外部标识，检索与实验记录对应的具体抗原序列。精确抗原序列能够提供最直接的单序列信息，尤其有助于捕捉突变位点、局部氨基酸变化以及可能影响表位识别的细粒度差异。

第二条路径是同源序列比对路径（MSA Path）。当精确抗原序列难以确认，或希望引入更广泛的进化背景时，可以基于同源序列构建多序列比对。MSA 表征能够反映抗原家族中相对保守或变化较大的区域，为模型提供进化约束层面的上下文。保守区域往往与蛋白功能维持相关，也可能对应更稳定的抗体识别区域。

这两条路径提供的信息并不完全相同。Exact Path 更关注“当前实验中的这个抗原具体是什么”，MSA Path 更关注“这个抗原所属家族中哪些位置更受进化约束”。在亲和力排序任务中，精确序列通常应承担主要区分作用，而 MSA 信息更适合作为补充背景，用于增强模型对保守区域和家族特征的理解。

因此，项目设置三类抗原表征方案用于比较：

| 方案 | 抗原输入 | 编码方式 | 主要作用 |
| --- | --- | --- | --- |
| Exact-Only | 精确抗原序列 | ESM-2 编码后池化 | 捕捉具体抗原和突变差异 |
| MSA-Only | 同源序列比对矩阵 | ESM-MSA 编码后聚合 | 捕捉进化约束和家族背景 |
| Exact + MSA | 精确序列与 MSA 双路输入 | 两路编码后融合 | 同时利用单点差异和进化背景 |

需要注意的是，MSA 表征也可能带来一定风险。当多个突变株属于同一抗原家族时，MSA 可能使它们的表征过于接近，从而削弱模型区分具体突变株的能力。因此，MSA-Only 不应被预设为最优方案，而应通过消融实验验证其实际贡献。

## 7. 缺失信息处理：显式标记，而不是伪造特征

真实数据中并不总能同时获得精确抗原序列和高质量 MSA。为了让模型在信息不完整的情况下仍能运行，需要设计稳定的降级策略。

本项目的原则是：缺失信息可以被标记，但不能被伪造成真实生物学信号。也就是说，如果某一路抗原表征无法获得，可以在张量层面使用占位向量保持输入形状一致，但必须同时提供显式 mask，让模型知道该路径不可用。尤其在使用注意力机制时，缺失路径不能作为有效 token 参与 attention 权重计算，否则全零向量可能干扰注意力分布，影响有效特征的聚合。

因此，融合模块需要同时接收特征向量和有效性标记。有效路径参与编码与聚合；无效路径只用于维持批处理形状，不参与实际语义计算。这样的设计既保证了工程上的稳定性，也避免了模型将“缺失模式”误解为某种生物学特征。

## 8. 抗体表征：兼容 Fv 与 VHH 的统一编码

抗体端的主要挑战在于不同抗体形态的序列结构不同。传统 Fv 抗体通常由 VH 与 VL 两部分组成，而纳米抗体 VHH 只有单个重链可变区。为了在统一模型中处理这两类输入，项目采用显式结构标记与序列拼接相结合的方式。

对于 Fv 抗体，模型将 VH 和 VL 按照固定顺序拼接，并在序列开头和链间位置加入特殊标记，用于提示模型当前输入的抗体类型和链结构。对于 VHH 抗体，则使用 VHH 类型标记加单链序列表示。这样做的目的不是人为增加生物学信息，而是帮助预训练蛋白语言模型区分不同的抗体输入格式。

在编码器选择上，项目计划比较通用蛋白语言模型和抗体专用语言模型的效果。ESM-2 能够提供较强的通用蛋白序列表征能力；AbLang-2 等抗体专用模型则可能更好地捕捉 CDR 区域多样性、框架区保守性以及抗体序列的特殊分布。两类编码器的效果需要通过消融实验比较，而不在设计阶段直接预设结论。

## 9. 模型架构：编码、交互与排序打分

模型整体由四个部分组成：抗原编码器、抗体编码器、抗体-抗原交互模块，以及最终的排序打分头。

抗原编码器负责将 Exact Path 和 MSA Path 中获得的抗原信息转换为向量表示。抗体编码器负责将 VH/VL 或 VHH 序列转换为残基级或序列级表示。二者分别提供抗原侧和抗体侧的基础特征。

在获得两侧特征后，模型使用交叉注意力机制学习抗体与抗原之间的条件依赖关系。这里的交叉注意力并不等同于真实三维结构模拟，而是一种特征交互方式：它允许模型在抗原上下文下重新加权抗体残基信息，或在抗体上下文下关注抗原侧更相关的区域。相比简单拼接后送入 MLP，交叉注意力能够提供更细粒度的特征匹配能力。

交互后的残基级特征需要进一步聚合为固定维度表示。项目采用 Attention Pooling 将变长序列表示压缩为固定长度向量。该池化层通过可学习查询向量从残基级表示中提取关键信息，使模型能够在不同抗体长度和不同链结构下生成统一的全局表征。

最终，排序打分头接收聚合后的抗体-抗原交互向量，输出一个一维实数分数。该分数不对应具体的物理单位，而是表示模型对该抗体在当前抗原背景下相对优劣的判断。分数越高，表示模型认为该候选抗体越值得优先排序。

## 10. 训练目标：Pairwise RankNet Loss

由于任务评价指标关注排序一致性，训练目标也应围绕相对顺序设计。本项目采用 Pairwise Ranking 的训练方式：在同一同质分组内抽取两个抗体样本，比较它们的真实标签高低，并要求模型输出的分数差与真实排序方向一致。

设模型对样本 \(i\) 和样本 \(j\) 输出的分数分别为 \(s_i\) 和 \(s_j\)。模型认为样本 \(i\) 优于样本 \(j\) 的概率可以表示为：

$$
P_{ij} = \frac{1}{1 + e^{-\sigma(s_i - s_j)}}
$$

其中，\(\sigma\) 是控制分数差映射敏感度的缩放参数。如果真实标签显示样本 \(i\) 优于样本 \(j\)，则目标概率为 1；反之为 0。通过交叉熵损失优化大量样本对，模型逐渐学习在每个同质分组内部给出更合理的亲和力排序。

这种训练方式与 Spearman 评价指标具有较好的任务一致性。它不强迫模型拟合不同实验体系下的绝对数值，而是让模型专注于在可比样本之间判断相对优劣。

## 11. 评估与消融实验设计

项目最终以 Spearman 等级相关系数作为主要评价指标。除了整体 Spearman 外，还应关注不同分组、不同抗原类型、不同指标类型以及不同抗原信息完整度下的表现。这样可以避免模型只在少数大分组上表现良好，而在数据稀疏或抗原信息缺失的场景中失效。

为了判断各模块的真实贡献，项目设置以下消融方向：

| 消融方向 | 对比内容 | 目的 |
| --- | --- | --- |
| 抗原表征 | Exact-Only / MSA-Only / Exact+MSA | 判断精确序列与进化信息的贡献 |
| 抗体编码器 | ESM-2 / AbLang-2 | 比较通用蛋白模型与抗体专用模型 |
| 交互模块 | 简单拼接 / Cross-Attention | 判断显式交互是否提升排序能力 |
| 池化方式 | Mean Pooling / Attention Pooling | 判断可学习池化是否更适合变长序列 |
| 损失函数 | 回归损失 / Pairwise Ranking Loss | 验证排序学习是否更匹配任务目标 |
| 缺失信息处理 | 无 mask / 显式 mask | 验证缺失路径是否会干扰模型判断 |

这些消融实验的意义不只是追求分数提升，也用于验证项目设计中的关键假设。例如，Exact Path 是否确实比 MSA-Only 更能区分突变株；Cross-Attention 是否比简单拼接更能捕捉抗体-抗原之间的条件依赖；Pairwise Loss 是否比回归损失更适合异构亲和力数据。

## 12. 项目特点

本项目的核心特点可以概括为四点。

第一，任务表述更贴近评价指标和实际筛选需求。项目不直接追求绝对亲和力数值预测，而是将问题建模为同一抗原背景下候选抗体的相对排序，从而更自然地对应 Spearman 评价方式。

第二，数据处理强调可比性。通过同质分组和指标方向统一，项目尽量避免跨实验体系、跨指标尺度和跨抗原背景带来的错误监督信号。

第三，抗原表征兼顾精确差异与进化背景。Exact Path 用于捕捉具体抗原序列和突变信息，MSA Path 用于补充同源家族中的保守性与进化约束，两者共同服务于更稳健的抗原上下文建模。

第四，模型结构围绕抗体-抗原交互展开。通过预训练蛋白语言模型、交叉注意力和排序打分头，模型能够在序列层面学习候选抗体与目标抗原之间的条件匹配关系，并输出可用于候选筛选的相对得分。

## 13. 当前边界与后续方向

本项目目前主要聚焦于序列层面的抗体-抗原亲和力排序。由于数据中并非所有样本都包含高质量结构信息，模型不会在初始阶段依赖三维复合物结构作为必要输入。交叉注意力模块用于学习序列特征之间的统计交互关系，而不是替代真实分子对接或结构动力学模拟。

后续工作可以从三个方向继续推进。首先，在数据层面进一步完善抗原序列检索和指标标准化规则，提高训练标签的可靠性。其次，在模型层面比较不同抗体编码器、抗原融合策略和交互模块的实际效果，避免盲目堆叠复杂结构。最后，在评估层面增加分组级分析和错误案例分析，理解模型在哪些抗原类型、指标体系或缺失信息场景下更容易失效。

总体而言，本项目希望在异构亲和力数据条件下，构建一个以排序学习为核心、兼顾抗原上下文和抗体序列特征的计算筛选框架，为抗体候选分子的早期优选提供可复现、可解释的模型方案。
